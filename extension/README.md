# TaggingBox Chrome 확장 프로그램

웹 페이지의 텍스트를 손쉽게 선택하여 TaggingBox에 저장할 수 있는 Chrome 확장 프로그램입니다.

## 기능

- 웹 페이지에서 텍스트를 선택하여 저장
- 텍스트를 저장할 박스 선택
- 태그 추가 및 메모 작성 가능
- 선택한 콘텐츠에 대한 URL 자동 저장

## 설치 방법

### 개발자 모드로 설치

1. Chrome 브라우저를 열고 주소창에 `chrome://extensions/`를 입력합니다.
2. 우측 상단의 "개발자 모드"를 활성화합니다.
3. "압축해제된 확장 프로그램을 로드합니다." 버튼을 클릭합니다.
4. `extension` 폴더를 선택합니다.

### 사전 준비 사항

- 확장 프로그램을 사용하기 전에 TB Hub에 로그인되어 있어야 합니다.
- 최소 하나 이상의 박스가 생성되어 있어야 합니다.

## 사용 방법

1. 웹 페이지에서 저장하고 싶은 텍스트를 마우스로 드래그하여 선택합니다.
2. 브라우저 상단의 TaggingBox 확장 프로그램 아이콘을 클릭합니다.
3. 팝업 창에서 선택한 텍스트를 확인하고, 필요한 경우 수정합니다.
4. 저장할 박스를 선택합니다.
5. 제목과 메모를 추가할 수 있습니다(선택사항).
6. 태그를 추가할 수 있습니다(선택사항).
7. "저장하기" 버튼을 클릭하여 선택한 콘텐츠를 저장합니다.

## 주의 사항

- 이 확장 프로그램은 TB Hub와 연동되므로, API 엔드포인트가 올바르게 설정되어 있어야 합니다.
- 실제 배포 시에는 `API_BASE_URL`을 실제 서버 주소로 변경해야 합니다.
- 인증 토큰을 로컬에서 가져오기 때문에 TB Hub 웹 애플리케이션과 동일한 브라우저 환경에서 사용해야 합니다.
