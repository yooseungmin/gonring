# 아이콘 생성 안내

`icons` 폴더에 다음 크기의 PNG 파일이 필요합니다:

- icon16.png (16x16 픽셀)
- icon48.png (48x48 픽셀)
- icon128.png (128x128 픽셀)

다음 두 가지 방법으로 아이콘을 생성할 수 있습니다:

## 방법 1: 온라인 SVG to PNG 변환 도구 사용

1. `icons/icon.svg` 파일을 열어서 SVG 코드를 복사합니다.
2. 온라인 SVG to PNG 변환기(예: https://svgtopng.com/)에 붙여넣고 각 크기로 변환합니다.
3. 변환된 파일을 `icons` 폴더에 저장합니다.

## 방법 2: 이미지 편집 프로그램 사용

1. Adobe Illustrator, Inkscape 또는 다른 벡터 그래픽 편집 프로그램에서 SVG를 열고 필요한 크기로 내보냅니다.
2. 내보낸 파일을 `icons` 폴더에 저장합니다.

## 임시 아이콘 사용

테스트를 위해 임시로 다른 아이콘을 사용할 수도 있습니다:

1. 무료 아이콘 사이트(예: https://www.flaticon.com/ 또는 https://material.io/resources/icons/)에서 적절한 아이콘을 다운로드합니다.
2. 각 크기에 맞게 이름을 변경하고 `icons` 폴더에 저장합니다.
